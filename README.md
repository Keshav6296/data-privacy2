## Upload to GitHub

Create a repository, choose **Add file → Upload files**, and upload this `README.md` together with the ten numbered `.md` files. GitHub renders the README as the repository home page and each practical as a separate readable page.

## Scope note

This is an educational desk review. Public-policy descriptions are distinguished from student analysis and hypothetical scenarios. It is not an internal audit, legal opinion, or claim about Meta's non-public systems. Re-check linked sources before submission because policies and laws can change.
